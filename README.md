# Pizzaria BMG Portfolio

Financial analysis, scenario simulation, and QA auditing for a business model canvas in Python.

## Overview

This project structures a business model canvas (BMG Canvas) for a pizzeria into a clear, reproducible portfolio repository. It combines a spreadsheet model, business and audit documentation, a Python financial scenario simulator, and automated validation tests with `pytest`.
